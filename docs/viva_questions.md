# Viva Questions

1. What is machine learning?
   - It is the process by which systems learn patterns from data to make predictions.
2. What is classification?
   - It predicts categories such as Available, Limited, or Discontinued.
3. What is regression?
   - It predicts continuous values such as price or waiting days.
4. What is a Random Forest?
   - It combines many decision trees to reduce variance and improve accuracy.
5. What is a Decision Tree?
   - A tree-based model that splits data based on feature conditions.
6. What is preprocessing?
   - It cleans and transforms raw data before training.
7. Why do we split data into train/test sets?
   - To measure model performance on unseen data.
8. What is overfitting?
   - When a model memorizes training data and performs poorly on new data.
9. What is accuracy?
   - The fraction of correct predictions.
10. What is precision?
   - Of all positive predictions, how many were actually correct.
11. What is recall?
   - Of all actual positives, how many were correctly identified.
12. What is F1 score?
   - A balance between precision and recall.
13. What is MAE?
   - Mean Absolute Error, the average absolute difference between actual and predicted values.
14. What is RMSE?
   - Root Mean Squared Error, more sensitive to larger errors.
15. What is R²?
   - Coefficient of determination showing model fit quality.
16. Why use OneHotEncoder?
   - It converts categorical variables into numeric values for ML models.
17. What is the purpose of imputation?
   - To fill missing values so models can train without errors.
18. What is a stratified split?
   - It ensures class proportions are maintained in train and test sets.
19. What is Flask?
   - A lightweight Python web framework for building REST APIs.
20. What is a REST API?
   - An API that uses HTTP methods such as GET and POST to communicate.
21. What is the purpose of the Flask health endpoint?
   - To confirm the server is running.
22. What is Flutter?
   - A UI toolkit for building cross-platform mobile applications.
23. What is Firebase?
   - A cloud platform that provides backend features such as authentication and storage.
24. Why is Firebase not used for ML predictions here?
   - Because the ML logic is handled by the Flask API.
25. What is a synthetic dataset?
   - A dataset generated or simulated for demonstration and prototype work.
26. Why should we label demo data?
   - To prevent users from assuming the predictions are based on live inventory.
27. Why should we avoid target leakage?
   - Leakage makes the model look better than it actually is on unseen data.
28. Why is it important to validate user input?
   - To avoid invalid and unsafe predictions.
29. What is a garage recommendation score?
   - A transparent score based on availability, waiting time, price, and garage suitability.
30. What is a project limitation?
   - Any constraint such as limited data, non-live inventory, or environment restrictions.
